What's inside

Built different.

🧠
AI Tutor — Problem Aware
Gemini API receives your full problem statement, difficulty, tags, and your live code from the editor. Hints adapt to your actual solution approach in real time.
📊
Real-Time Bubble Analytics
Topic mastery visualized as bubbles — fill level = solved/total per category. Updates instantly on every solve and unsolve event. No page reload.
🔥
16-Week Activity Heatmap
GitHub-style heatmap tracking your last 16 weeks. Color intensity scales with daily problem volume — the more you grind, the brighter it glows.
⚡
Streak System
Day-based streaks tracking current and maximum. Solve after midnight and your streak stays alive. Miss a day — reset and rebuild stronger.
💾
Persistent Workspaces
Code and AI chat saved per user per problem across sessions. Return and pick up exactly where you left off — powered by 1.5s debounced autosave.
🔐
OAuth 2.0 + JWT Auth
Google and GitHub OAuth via authorization code flow. Your own JWT issued post-verification — sessions fully independent of third-party tokens.

Get started

Local Setup

1Clone the repo
git clone https://github.com/rupesh1285/Developers.git
cd Developers
2Install dependencies
# Frontend
cd client && npm install

# Backend
cd ../server && npm install
3Configure environment variables
# /server/.env
MONGO_URI=your_mongodb_atlas_uri
JWT_SECRET=your_jwt_secret
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
GITHUB_CLIENT_ID=your_github_client_id
GEMINI_API_KEY=your_gemini_api_key
4Run the app
# Terminal 1 — Backend
cd server && npm run dev

# Terminal 2 — Frontend
cd client && npm run dev
✓  Frontend: http://localhost:5173  ·  Backend: http://localhost:5000
