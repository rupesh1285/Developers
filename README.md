## ⚡️ Overview
**Finalist** is a premium, distraction-free environment designed to help developers master data structures, algorithms, and technical interviews. Combining a blazing-fast code editor, an integrated AI tutor, and real-time behavioral analytics, Finalist bridges the gap between studying code and actually writing it under pressure.

---

## 🚀 Engineering Achievements
Finalist was built with a strict focus on front-end optimization and back-end efficiency.

* **Ultra-Low Latency API (150ms - 300ms):** The MongoDB backend utilizes heavily optimized queries (`.lean()`, strict `.select()` projections, and Node.js in-memory caching) to deliver massive analytics payloads in milliseconds.
* **100/100 Lighthouse SEO:** Fully optimized meta-tags, Open Graph integrations, and semantic HTML structure.
* **92+ Performance Score:** Reached by aggressively lazy-loading heavy DOM nodes (like the CodeMirror IDE) and implementing native React virtualization to keep the DOM light.
* **Optimistic UI Rendering:** Database mutations (like checking off a problem) update the UI, the streak, and the 16-week heatmap instantly in React memory while syncing silently with the server, completely eliminating loading flickers.

---

## ✨ Core Features

* **📱 Complete Responsiveness:** A fully fluid, cross-device UI. Features a complex side-by-side desktop view that gracefully degrades into a smooth bottom-sheet mobile architecture.
* **⚡️ Draggable IDE Workspace:** A resizable, split-screen CodeMirror environment with Dracula syntax highlighting, allowing you to read problems and write code seamlessly.
* **🧠 Context-Aware AI Tutor:** Stuck on a hard problem? The integrated AI assistant reads your current code context to provide hints—without giving away the whole solution.
* **📊 Real-Time Analytics Engine:** Instantly tracks your 7-day streak, absolute time spent, and maps your activity across a 16-week GitHub-style heatmap.
* **🫧 Dynamic Topic Cluster:** A visually stunning, physics-based bubble chart that categorizes and weights your solved algorithms by topic (Arrays, Graphs, DP).

## 💻 Tech Stack

### Frontend Architecture
* **React 18** (Hooks, Custom Refs, Context API)
* **Vite** (esbuild/Rolldown optimized bundling)
* **CodeMirror 5** (IDE Engine & Syntax Highlighting)
* **Vanilla CSS3** (Glassmorphism, custom keyframe animations, grid/flexbox)

### Backend Engine
* **Node.js & Express** (REST API Architecture)
* **MongoDB & Mongoose** (Optimized Schema & Indexing)
* **JWT Authentication** (Stateless, secure auth flows)
* **Uptime/Cron** (Automated health-checks to ensure 24/7 server availability)
